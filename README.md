> Plataforma SaaS de punto de venta **multi-empresa** con pantalla de cocina (KDS) en **tiempo real vía Socket.io** (con modo offline), inventario con recetas y almacenes, módulo económico, **facturación CFDI 4.0** y panel de super admin con planes y suscripciones. Dos apps (web + móvil) con Expo Router compartiendo lógica en un monorepo.

**Stack:** React Native · Expo Router · TypeScript · Node.js · Express · Prisma · PostgreSQL · Socket.io

**Stack:** React 19 · TypeScript · Vite · Tailwind CSS 4 · Express 5 · Prisma 7 · PostgreSQL

### 🖥️ Media Link Overlay — Conexión Remota de Baja Latencia
